Sync performance
Frames per second to analyze. Lower values reduce CPU load. (Default: 20)
Choose the RGB frame size sent through the sampler. Higher resolution preserves finer spatial detail but uses more CPU and memory.
Stretch fills the 16:9 sampler exactly. Fit preserves the source aspect ratio with bars; Crop preserves it while trimming the excess edges.
Use Auto for television or DVD sources that carry interlaced frame flags. On forces deinterlacing for every frame and uses more CPU.
Size of the neighborhood sampled around each Hue channel's screen position (1-50%, default: 15%). Smaller values follow fine detail; larger values reduce noise.
Choose how each Hue channel's sampling region is combined. Average is the stable default; center-weighted favors detail near the mapped position; center pixel follows the exact position.
Blend the previous frame into new colors to reduce flicker (0-90%, default: 0). Higher values create smoother but slower transitions.
